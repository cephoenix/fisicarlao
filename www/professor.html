Pedidos de mudança

Conectar este aparelho

Esta área é só do professor. Aqui você pede mudanças no FisiCarlão em português, e o Claude altera e publica o app.

Para isso, este aparelho precisa de uma chave de acesso do GitHub, que fica guardada só aqui.

  1. Abra github.com → criar token.
  2. Repository access: “Only select repositories” → fisicarlao.
  3. Permissions → Repository → Issues: “Read and write”. Nenhuma outra.
  4. Clique em Generate token e cole abaixo.

Novo pedido

Explique o que quer mudar, como explicaria para um colega. O Claude responde aqui, faz a mudança e publica.
